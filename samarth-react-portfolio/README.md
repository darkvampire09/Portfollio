# Samarth React Portfolio

## Run locally
1. Install Node.js.
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev

## Email notifications
The contact form uses FormSubmit's AJAX endpoint:
https://formsubmit.co/ajax/dedgesamarth@gmail.com

On the first real submission, FormSubmit may send an activation email to dedgesamarth@gmail.com. Open that email and activate the form. After activation, portfolio enquiries are delivered to that inbox.

No backend, database, or server is required.
